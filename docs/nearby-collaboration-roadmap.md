# 近场协作能力路线图

本文档记录近聊在核心聊天链路稳定之后的体验演进方向。所有能力都围绕“局域网内更直接、更轻量的团队协作”展开，并按可独立验收、可随时交付的顺序逐项实现。

## 实施原则

- 先完成一条可真实使用的最小闭环，再补充高级配置。
- 优先复用现有单聊、群聊、WebSocket、MinIO 与 Electron 能力。
- 交互反馈必须即时、可理解，并兼顾明亮/黑暗主题、窄窗口和减少动态效果偏好。
- 每项功能完成后执行单元测试、类型检查、生产构建和浏览器验收，并形成独立本地 Git 提交。
- 局域网内部团队是当前边界，不引入公网 SaaS、多租户或复杂风控设计。

## 阶段技术落点

1. **直接操作层**：头像投递、敲一下，完善联系人作为协作入口的反馈模型。
2. **桌面效率层**：剪贴板接力、桌面浮岛，扩展 Electron 主进程、预加载桥接和窗口管理。
3. **内容表达层**：圈图回复、状态气泡、语音明信片、消息反应，复用现有消息与附件域。
4. **临时协作层**：闪聊房间，为会话增加明确生命周期。
5. **团队概览层**：今日团队雷达，只呈现协作线索，不做监控或个人排名。

## 当前实施记录

### 1. 头像投递

- 投递目标：联系人列表以及最近会话中的单聊头像。
- 支持内容：拖拽选中文本、操作系统中的图片或普通文件。
- 发送语义：松开即发送；群聊不作为“联系人头像投递”目标。
- 保护规则：一次仅发送一个文件，最大 50 MB；并发上传期间不接受第二次头像投递。
- 失败恢复：上传前失败不产生附件；消息发送失败时保留在待发送队列，可沿用现有重试/丢弃能力。
- 交付结果：联系人和最近单聊均支持投递；明亮/黑暗主题、减少动态效果与减少透明度偏好均有对应样式。
- 验证结果：拖拽解析、标准消息链路、全量类型检查、单元测试、生产构建及 1280×720 浏览器界面均已通过。

### 2. 敲一下

- 发起入口：在线单聊头部显示“敲一下”；离线或实时连接中断时给出就地提示。
- 传输语义：由 HTTP 完成身份与会话校验，再通过 WebSocket 向接收方所有在线标签页即时投递，不写入消息历史。
- 防打扰：同一发送方对同一联系人设置 3 秒进程内冷却；提示音和系统通知沿用用户现有偏好。
- 接收体验：头像波纹、轻微聊天表面反馈和 4.2 秒自动消失浮层；来自其他会话时可一键直达。
- 验证结果：事件解析与浮层组件测试、双账号真实 WebSocket 冒烟、明亮主题收发浏览器验收均已通过。

### 3. 剪贴板接力

- 发起方式：Electron 注册 `CommandOrControl+Shift+V` 全局快捷键，并在系统信息面板与托盘中提供手动入口；普通 Web 页面不展示桌面专属入口。
- 内容边界：主进程在用户主动发起后读取剪贴板，支持最多 5000 字文本与不超过 50 MB 的 PNG 图片；文本和图片同时存在时可在预览中切换。
- 发送保护：弹窗默认按最近会话排列联系人，必须明确选择目标并再次确认；发送沿用现有单聊、MinIO 上传、待发送队列与失败重试链路。
- 可诊断性：界面展示全局快捷键是否注册成功；被其他应用占用时保留托盘与系统信息面板中的手动入口。
- 验证结果：主进程剪贴板解析、弹窗组件和 Electron 桥接测试均已通过；真实 Electron 渲染进程已验证系统剪贴板读取、快捷键状态、目标确认及消息送达完整链路。

### 4. 桌面浮岛

- 窗口形态：Electron 独立创建 380×600 无边框置顶窗口，不占任务栏，可拖动，并在全屏工作区保持可见。
- 快速操作：展示最近 4 个会话、未读数量与最后 6 条消息；可切换会话、直接发送文本或跳回主窗口查看完整内容。
- 状态同步：浮岛和主窗口共享登录存储，分别连接同一 WebSocket 与标准 API；消息、未读、在线状态和会话顺序由服务端实时同步。
- 本机记忆：系统信息面板、应用菜单和托盘均可控制开关；开关及最后位置保存到 Electron `userData/desktop-island.json`，显示器变化时自动回到主屏安全区域。
- 验证结果：窗口位置容错、浮岛组件与发送测试通过；真实 Electron 已验证开启/关闭、登录态共享、文本送达、主窗口同步、移动位置及重启恢复。
