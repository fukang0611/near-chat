# 近场协作能力路线图

本文档记录近聊在核心聊天链路稳定之后的体验演进方向。所有能力都围绕“局域网内更直接、更轻量的团队协作”展开，并按可独立验收、可随时交付的顺序逐项实现。

## 实施原则

- 先完成一条可真实使用的最小闭环，再补充高级配置。
- 优先复用现有单聊、群聊、WebSocket、MinIO 与 Electron 能力。
- 交互反馈必须即时、可理解，并兼顾明亮/黑暗主题、窄窗口和减少动态效果偏好。
- 每项功能完成后执行单元测试、类型检查、生产构建和浏览器验收，并形成独立本地 Git 提交。
- 局域网内部团队是当前边界，不引入公网 SaaS、多租户或复杂风控设计。

## 阶段技术落点

1. **直接操作层**：头像投递、敲一下，完善联系人作为协作入口的反馈模型。
2. **桌面效率层**：剪贴板接力、桌面浮岛，扩展 Electron 主进程、预加载桥接和窗口管理。
3. **内容表达层**：圈图回复、状态气泡、语音明信片、消息反应，复用现有消息与附件域。
4. **临时协作层**：闪聊房间，为会话增加明确生命周期。
5. **团队概览层**：今日团队雷达，只呈现协作线索，不做监控或个人排名。

## 当前实施记录

### 1. 头像投递

- 投递目标：联系人列表以及最近会话中的单聊头像。
- 支持内容：拖拽选中文本、操作系统中的图片或普通文件。
- 发送语义：松开即发送；群聊不作为“联系人头像投递”目标。
- 保护规则：一次仅发送一个文件，最大 50 MB；并发上传期间不接受第二次头像投递。
- 失败恢复：上传前失败不产生附件；消息发送失败时保留在待发送队列，可沿用现有重试/丢弃能力。
- 交付结果：联系人和最近单聊均支持投递；明亮/黑暗主题、减少动态效果与减少透明度偏好均有对应样式。
- 验证结果：拖拽解析、标准消息链路、全量类型检查、单元测试、生产构建及 1280×720 浏览器界面均已通过。

### 2. 敲一下

- 发起入口：在线单聊头部显示“敲一下”；离线或实时连接中断时给出就地提示。
- 传输语义：由 HTTP 完成身份与会话校验，再通过 WebSocket 向接收方所有在线标签页即时投递，不写入消息历史。
- 防打扰：同一发送方对同一联系人设置 3 秒进程内冷却；提示音和系统通知沿用用户现有偏好。
- 接收体验：头像波纹、轻微聊天表面反馈和 4.2 秒自动消失浮层；来自其他会话时可一键直达。
- 验证结果：事件解析与浮层组件测试、双账号真实 WebSocket 冒烟、明亮主题收发浏览器验收均已通过。

### 3. 剪贴板接力

- 发起方式：Electron 注册 `CommandOrControl+Shift+V` 全局快捷键，并在系统信息面板与托盘中提供手动入口；普通 Web 页面不展示桌面专属入口。
- 内容边界：主进程在用户主动发起后读取剪贴板，支持最多 5000 字文本与不超过 50 MB 的 PNG 图片；文本和图片同时存在时可在预览中切换。
- 发送保护：弹窗默认按最近会话排列联系人，必须明确选择目标并再次确认；发送沿用现有单聊、MinIO 上传、待发送队列与失败重试链路。
- 可诊断性：界面展示全局快捷键是否注册成功；被其他应用占用时保留托盘与系统信息面板中的手动入口。
- 验证结果：主进程剪贴板解析、弹窗组件和 Electron 桥接测试均已通过；真实 Electron 渲染进程已验证系统剪贴板读取、快捷键状态、目标确认及消息送达完整链路。

### 4. 桌面浮岛

- 窗口形态：Electron 独立创建 380×600 无边框置顶窗口，不占任务栏，可拖动，并在全屏工作区保持可见。
- 快速操作：展示最近 4 个会话、未读数量与最后 6 条消息；可切换会话、直接发送文本或跳回主窗口查看完整内容。
- 状态同步：浮岛和主窗口共享登录存储，分别连接同一 WebSocket 与标准 API；消息、未读、在线状态和会话顺序由服务端实时同步。
- 本机记忆：系统信息面板、应用菜单和托盘均可控制开关；开关及最后位置保存到 Electron `userData/desktop-island.json`，显示器变化时自动回到主屏安全区域。
- 验证结果：窗口位置容错、浮岛组件与发送测试通过；真实 Electron 已验证开启/关闭、登录态共享、文本送达、主窗口同步、移动位置及重启恢复。

### 5. 圈图回复

- 发起入口：图片放大预览左下角提供“圈图回复”，下载原图仍保持独立按钮，普通附件不展示标注入口。
- 标注能力：支持矩形、箭头与自由画笔，提供 4 种高对比颜色、撤销、重做、清空、取消和键盘 `Ctrl/Cmd+Z`；Pointer Events 同时覆盖鼠标、触控笔与触屏。
- 文件语义：原图只作为画布底图读取，不覆盖原 MinIO 对象；导出为最长边不超过 4096 像素的新 PNG，并沿用 50 MB 附件限制。
- 发送链路：标注图走现有上传接口与 MinIO 私有存储，再引用原图片消息进入统一待发送队列，弱网失败时可沿用消息重试。
- 验证结果：画布几何、生成文件、预览入口和引用发送测试通过；真实浏览器已验证矩形、箭头、撤销/重做、明暗主题、MinIO 上传及引用消息送达。

### 6. 状态气泡

- 设置入口：个人设置提供“专注中、开会中、午休、外出”四种预设，同时允许 40 字以内的自定义状态。
- 有效时间：可选 30 分钟、1 小时、4 小时或今天结束；服务端只接受 1 分钟至 24 小时内的时间，避免状态退化为长期签名。
- 展示范围：当前用户侧边栏、联系人列表、最近单聊和单聊头部共用同一状态资料；不插入消息区，也不会触发新消息通知。
- 过期语义：服务端序列化时过滤过期记录，前端气泡自身每 30 秒复核一次，到点无需等待 WebSocket 事件即可消失。
- 实时同步：设置和清除状态后广播现有 `users.changed` 事件，所有在线客户端复用资料刷新链路即时更新。
- 验证结果：有效期边界、服务端过期过滤、前端自动消失与设置交互测试均通过；真实浏览器完成个人设置、联系人和聊天头部同步验收。

### 7. 闪聊房间

- 创建入口：统一群聊创建器支持“常驻群聊 / 闪聊房间”切换；闪聊可选 30 分钟、2 小时、8 小时或 24 小时，并沿用现有成员选择。
- 生命周期：`conversations.expires_at` 非空即表示闪聊；服务端允许 5 分钟至 7 天的有效期，为后续 API 客户端保留受控扩展空间。
- 到期行为：房间不删除、不退出成员，统一转为只读；标准发送接口在幂等重试之后执行到期校验，拒绝任何新的文本或附件消息。
- 文件边界：到期不会自动删除 MinIO 附件，避免计时任务破坏历史；用户主动解散房间时继续走既有附件回收与失败重试流程。
- 展示范围：最近会话、聊天头部、会话介绍和 Electron 桌面浮岛均展示倒计时或“闪聊已结束”，输入器到期后同步锁定。
- 验证结果：有效期边界、倒计时切换、创建交互、主界面与浮岛只读测试通过；真实浏览器已验证创建、活跃期发送、到期展示、输入锁定及服务端 `409` 拒绝。

### 8. 语音明信片

- 发起入口：消息编辑器提供独立麦克风按钮；只有用户点击“开始录制”后才调用麦克风授权，不在登录或进入会话时提前索取权限。
- 录制边界：单段最长 60 秒、最大 8 MB；优先使用 `WebM + Opus`，并兼容浏览器可用的 MP4/WebM 录制格式，达到上限后自动停止。
- 发送确认：录音停止后先在本机生成试听地址，用户可以试听、重录或确认发送；未经确认的录音不会上传，关闭弹窗会释放媒体轨道与本地 Blob。
- 消息语义：服务端根据附件 MIME 将语音保存为独立 `AUDIO` 消息类型；文件继续进入现有 MinIO 私有附件链路，弱网失败沿用统一待发送队列和幂等重试。
- 播放体验：聊天区使用私有 Blob 播放器，提供播放/暂停、进度拖动、时长和独立下载；最近消息、引用、搜索与系统通知统一显示“语音明信片”摘要。
- 桌面权限：Electron 仅允许当前配置的近聊源站申请纯音频媒体权限，拒绝摄像头、外部源站和其他权限；macOS 打包信息包含麦克风用途说明，由系统在首次录制时显示正式授权框。
- 验证结果：消息类型、录音状态机、权限失败、授权等待期清理、试听发送、私有音频加载与下载测试通过；真实浏览器已验证授权界面、MinIO 音频消息、时长读取、播放与进度拖动。

### 9. 消息特效反应

- 反应集合：提供“赞、喜欢、哈哈、庆祝、在看、灵光”六种固定反应，服务端拒绝任意文本或未定义表情进入消息数据。
- 切换语义：同一成员可为消息添加多种反应；再次点击同一反应即移除。数据库以消息、成员和表情组成唯一键，并在事务中与消息撤回串行化。
- 聚合结果：消息 DTO 按表情返回总数及成员名称，聚合标签通过高亮区分自己的反应，悬停可查看具体成员。
- 实时同步：每次增减后向会话成员广播标准 `message.updated` 事件，所有在线标签页即时得到相同计数，无需刷新或轮询。
- 生命周期：已撤回消息拒绝新增反应并清空已有反应；已到期闪聊保持只读，只展示历史反应；发送中和发送失败的本地消息不开放反应入口。
- 交互反馈：消息悬停操作栏增加纯图标入口，选择面板不带文字噪声；首次添加显示一次短促表情与粒子反馈，减少动态效果偏好下完全关闭特效。
- 验证结果：预设校验、实时事件解析、选择面板、聚合标签、添加与移除测试通过；双账号真实浏览器已验证计数 `1 → 2 → 1 → 0`、明暗主题、成员名称、WebSocket 同步及撤回清理。

### 10. 今日团队雷达

- 全局入口：侧栏顶端提供雷达图标，存在待读消息时显示克制的红点并把数量写入无障碍标签；面板每 30 秒自动刷新，也可手动重新扫描。
- 当天口径：浏览器传入当前时区偏移，服务端据此计算本地“今天”的 UTC 起止边界，避免容器时区与使用者时区不同导致跨日统计错误。
- 在线信号：沿用现有 WebSocket 连接状态，展示当前在线人数、团队启用成员总数、在线成员头像及仍在有效期内的状态气泡。
- 会话范围：活动和待读查询都先关联当前用户的 `conversation_members`，退出或无权访问的会话不会出现在雷达结果中。
- 协作线索：活动区按最近时间展示今天的会话与最后一条有效消息；待读区展示未读数量和最新未读摘要。两类卡片均可直接进入对应会话。
- 数据边界：只统计团队总体消息数和会话数，不返回个人消息量，不展示成员排行；页脚持续说明该产品原则。
- 空状态与适配：今天没有活动、全部读完、无人在线、接口失败及后台刷新失败均有独立反馈；明亮/黑暗主题、窄窗口、减少透明度、增强对比度和减少动态效果均有对应样式。
- 验证结果：时区边界、数据加载、在线状态、活动/待读卡片、直达会话和双零状态测试通过；真实双账号浏览器已验证在线汇总、明暗主题、待读 `0 → 1 → 0`、卡片跳转、已读闭环及验收消息撤回清理。
